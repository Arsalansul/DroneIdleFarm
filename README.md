стек: unity 2022.3.62f, DOTS, Zenject
Ui:
- в топе счет каждой фракции
- внизу управление каждой фракцией
- справа поле ввода вменени для спавна ресурса и галочка для отображения пути дронов

Все настройки в конфиге Configs/GameSettingsInstaller

Фракции отличаются по цветам.

Логика:
дрон ищет ближайший не занятый ресурс, подлетает, собирает, летит обратно, сбрасывает ресурс (тут звук проигрывается и партиклы).
В момент сбора ресурса хотел проигрываеть звук, но не подобрал нормальный звук, поэтому закомментировал кусок кода.

Реализовал пул для объектов основного мира.

Код разделен по Assembly.
